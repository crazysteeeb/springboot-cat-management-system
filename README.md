# Spring Boot Cat Management System

A Java Spring Boot web application demonstrating CRUD operations, MVC architecture, database integration, and layered backend design.

## Overview

This project is a full-stack web application built using Spring Boot and the MVC design pattern.

The application allows users to manage records through a structured backend architecture consisting of:
- Controllers
- Services
- Repositories
- Database entities
- HTML template views

## Features

- CRUD functionality
- Spring Boot backend
- MVC architecture
- SQL database integration
- Repository/service layer separation
- HTML template rendering
- Form handling and data persistence

## Technologies Used

- Java
- Spring Boot
- Maven
- SQL
- HTML
- Thymeleaf
- MVC Architecture

## Project Structure

```text
src/main/java/

```

## Concepts Demonstrated

- MVC design pattern
- Layered backend architecture
- CRUD operations
- Dependency injection
- Spring Boot application structure
- Database schema integration
- Repository pattern

## How to Run

### Using Maven Wrapper

```bash
./mvnw spring-boot:run
```

### Or on Windows

```bash
mvnw.cmd spring-boot:run
```
